# Mini Game Catalog — เกมทัชสกรีนสำเร็จรูป 100 เกม

เว็บแคตตาล็อกสำหรับให้ลูกค้าเลือกแนวเกมที่ต้องการ **เล่นได้จริงทุกเกมบนหน้าเว็บ**
ออกแบบมาสำหรับจอสัมผัสในงานอีเวนต์ บูธแสดงสินค้า และหน้าร้าน

🔗 **เว็บไซต์:** https://ginomcclay28.github.io/mini-game-catalog/

---

## จุดเด่น

- **100 เกม เล่นได้จริง** ไม่ใช่ภาพนิ่งหรือวิดีโอ — เขียนด้วย Canvas ล้วน ไม่มี dependency ภายนอก
- **รองรับ 2 อัตราส่วนจอ** แนวนอน 1280×720 (16:9) และแนวตั้ง 720×1280 (9:16) ทุกเกม
  จัดวางใหม่จริงตามขนาดจอ ไม่ใช่ย่อภาพหรือใส่กรอบดำ
- **โหมดจำลองหน้างาน** ใส่กราฟฟิกจอสัมผัสพร้อมขาตั้งบนฉากงานอีเวนต์ ให้ลูกค้าเห็นภาพก่อนตัดสินใจ
- **สองภาษา** ไทย / อังกฤษ สลับได้ทั้งเว็บและในเกม
- **ยอดวิวและหัวใจ** นับจริง แยกตาม IP ผู้ชม พร้อมปุ่มเรียงตามความนิยม
- **เกม 2 ผู้เล่น 10 เกม** แบ่งครึ่งจอ แนวตั้งจะกลับหัวฝั่งบนให้นั่งหันหน้าเข้าหากันข้ามโต๊ะ

## โครงสร้างไฟล์

```
index.html              หน้าแรก — การ์ดเกม 10 หน้า ป๊อบอัพรายละเอียด ตัวเลือกแนวจอ
play.html               หน้าเล่นเกม
assets/css/style.css    สไตล์หน้าแรก
assets/js/
  brand.js              ⭐ จุดเดียวที่ปรับแต่ง — ชื่อแบรนด์ โลโก้ สี พื้นหลัง ราคา ตัวนับ
  games-data*.js        ข้อมูล 100 เกม (ชื่อ วิธีเล่น อุปกรณ์ จุดที่ปรับกราฟฟิกได้) ไทย+อังกฤษ
  engine.js             เอนจินกลาง — ขนาดจอ อินพุต คะแนน เวลา ชีวิต กรอบจอจำลอง
  stats.js              ยอดวิว + หัวใจ (hits.sh + abacus)
  app.js                ตรรกะหน้าแรก — แบ่งหน้า ฟิลเตอร์ เรียงลำดับ จำตำแหน่ง
games/pack1-10.js       โค้ดเกม แพ็กละ 10 เกม
_test/                  สคริปต์ทดสอบ (dev เท่านั้น ลบทิ้งได้)
```

## การปรับแต่งให้ลูกค้า

แก้ที่ **`assets/js/brand.js`** ไฟล์เดียว มีผลทั้งเว็บและทุกเกมทันที

```js
window.BRAND = {
  name: "YOUR BRAND",        // ชื่อแบรนด์
  logo: null,                // path รูปโลโก้
  gameBg: null,              // path ภาพพื้นหลังในเกม
  colors: { ... },           // ชุดสี 10 สี
  price: 9500,               // ราคาต่อเกม
  stats: { enabled, ns, hitsPath }   // ตัวนับยอดวิว/หัวใจ
};
```

> ราคา 9,500 บาท/เกม ครอบคลุมรูปแบบการเล่นมาตรฐานตามที่แสดงในเว็บนี้
> ลูกค้าปรับแต่งได้ในส่วนกราฟฟิก โลโก้ และภาพพื้นหลัง

### ตัวนับยอดวิว / หัวใจ

- **ยอดวิวรายหน้า** ใช้ badge จาก [hits.sh](https://hits.sh) — `hitsPath` ต้องขึ้นต้นด้วยชื่อโดเมนจริง
- **ยอดวิว/หัวใจรายเกม** ใช้ [abacus](https://abacus.jasoncameron.dev) (ฟรี ไม่ต้องสมัคร)
  คีย์มีอายุราว 6 เดือนนับจากครั้งล่าสุดที่ถูกเรียก เกมที่ไม่มีคนเปิดเลยเกินครึ่งปีตัวเลขจะรีเซ็ต
- ปิดทั้งระบบได้ที่ `stats.enabled = false` เว็บยังทำงานปกติ แค่ไม่มีตัวเลข
- หัวใจกดได้ครั้งเดียวต่อ IP ต่อเกม ยกเลิกไม่ได้

## รันบนเครื่องตัวเอง

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์

## เบราว์เซอร์ที่รองรับ

Chrome / Edge / Safari / Firefox รุ่นปัจจุบัน — ใช้ Canvas 2D และ Web Audio ที่รองรับกันทั่วไป
อีโมจิในเกมเลือกเฉพาะตัวที่มีในฟอนต์ระบบรุ่นเก่า (ก่อนปี 2018) เพื่อไม่ให้ขึ้นเป็นกล่องว่างบน Windows รุ่นเดิม
