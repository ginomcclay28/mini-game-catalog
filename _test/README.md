# สคริปต์ทดสอบ (สำหรับ dev เท่านั้น)

ไม่เกี่ยวกับตัวเว็บ ลบทิ้งได้ถ้าไม่ใช้

## ติดตั้งครั้งแรก

```
npm i @napi-rs/canvas
```

แล้วแก้ path `/tmp/node_modules/@napi-rs/canvas` ที่หัวไฟล์ให้ตรงกับเครื่องตัวเอง

## smoke.js — รันทุกเกมแบบไม่มีเบราว์เซอร์

รันเกมจริงบน canvas เกมละ ~15 วินาที พร้อมสุ่มแตะจอและเริ่มใหม่
จับ runtime error และเช็คว่าจอไม่ว่างเปล่า

```
node --expose-gc _test/smoke.js            # ทุกเกม (กินแรม ควรแบ่งรัน)
node --expose-gc _test/smoke.js 1 20       # เฉพาะเกมที่ 1-20
```

ครอบคลุม 100 เกม × 2 แนวจอ × 2 ภาษา = 400 เคส

## render.js — เรนเดอร์ภาพจริงไว้ตรวจ layout ด้วยตา

```
node _test/render.js land ./shots-land 1 25
node _test/render.js port ./shots-port 1 25
```

ได้ PNG เกมละ 1 ไฟล์ เอาไปไล่ดูว่ามีอะไรล้นขอบจอหรือซ้อนกันไหม
(ในสภาพแวดล้อมที่ไม่มีฟอนต์อีโมจิ ตัวละครที่เป็นอีโมจิจะไม่ขึ้น เป็นเรื่องปกติ)
